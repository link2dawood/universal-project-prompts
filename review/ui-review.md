# UI Review Prompt

Review the supplied interface or implementation against its intended user task and design system.

Check hierarchy, task completion, responsive behavior, keyboard/focus handling, accessible names/semantics/contrast, validation and feedback, loading/empty/error states, and consistency. Report concrete user-impacting issues with screen/component and reproduction steps, ordered by severity. Distinguish visual preferences from usability or accessibility defects; suggest targeted fixes and missing tests.

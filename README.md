# Universal Project Prompts

A categorized library of reusable prompts for the full software project lifecycle. Start with [shared/master-rules.md](shared/master-rules.md) and [shared/project-context.md](shared/project-context.md), then combine focused prompts as needed.

## Categories

- [Design](design/): interface concepts, screens, and platform conversions.
- [Development](development/): backend, database, mobile, and website implementation.
- [Marketing](marketing/): store listings, content, search, and discovery.
- [Release and deployments](release-deployments/): launch preparation and deployment operations.
- [Review](review/): focused code, API, Supabase, and UI reviews.
- [Recommendations](recommendations/): evidence-based product and engineering decisions.
- [Shared rules](shared/): reusable project context, standards, and workflow instructions.
- [Testing](testing/): platform and interface testing strategies.

## How to use

1. Copy the relevant prompt into your AI coding or planning tool.
2. Fill in bracketed project details and attach relevant code, designs, logs, or requirements.
3. State the desired output and constraints. Ask for assumptions to be separated from verified facts.
4. Use [shared/workflow.md](shared/workflow.md) to keep larger tasks incremental and verifiable.

Prompts guide work; they do not replace project-specific engineering judgment, security review, or platform policies.

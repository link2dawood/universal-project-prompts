# Project Context Template

Provide this context alongside focused prompts when useful:

- Project and purpose: [name, problem solved]
- Users and primary workflows: [audience, tasks]
- Platforms and environments: [web, mobile, extension, backend]
- Technology and versions: [languages, frameworks, services]
- Architecture and key paths: [modules, entry points]
- Design and coding conventions: [links or concise notes]
- Constraints: [compatibility, budget, privacy, deadlines]
- Definition of done: [observable acceptance criteria]
- Validation commands: [tests, lint, build]

Mark unknowns explicitly. Never include secrets or unnecessary personal data.

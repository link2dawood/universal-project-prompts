# Workflow Prompt

Work through this task in small, verifiable steps:

1. Identify the concrete behavior, owning code path, and acceptance criteria.
2. Inspect the smallest relevant implementation, tests, and conventions needed to form a testable hypothesis.
3. Make the smallest change that addresses the requirement.
4. Immediately run the most focused available check; repair local failures before broadening scope.
5. Review changes for regressions, unrelated edits, and missing documentation.
6. Report what changed, checks run and results, assumptions, and remaining risks.

Do not claim a check passed unless it was run successfully. Preserve unrelated work.

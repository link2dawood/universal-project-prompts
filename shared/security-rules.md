# Security Rules Prompt

Treat external input as untrusted and enforce authorization at the server-side trust boundary. Use least privilege, safe defaults, secure secret management, and data minimization. Never print or commit credentials, tokens, or private user data. Consider injection, access control, sensitive logging, dependency risk, and failure behavior relevant to the change. Document scope and residual uncertainty; do not claim security from a superficial scan.
